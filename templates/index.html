⚠ Delete ALL Shares — Final Confirmation
DANGER — This action is irreversible.
Every share grant and mountpoint on this server will be permanently removed.
  • All outgoing share grants across every account will be revoked.
  • All mounted shared folders in every mailbox will be deleted.
  • Existing manifests are not affected.
  • Shares can be recreated later using Apply Migration.

Apply Current Manifest State

Phase 1 — Create: 0 records flagged "Keep" will have their grants and mountpoints created or updated on this server. Accounts not present on this server are skipped automatically.

Phase 2 — Remove: 0 records flagged "Remove" will have their grants revoked and mountpoints deleted.

Removal of grants and mountpoints is irreversible. Creation is safe to repeat — already-existing shares are silently updated.
